A token launch radar that scores 198 pre-token protocols by implied value from public TVL (flat 0.25× TVL) and flags each as FARM, SKIP, or THIN, with a ranked board, an interactive dashboard, and a machine-readable dossier.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
